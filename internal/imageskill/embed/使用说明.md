# DeepRouter 生图 Skill（deeprouter-image-api）使用说明

## 这是什么

这是一个可以装进「支持本地 Skill 的 AI 工具」里的 Skill 文件夹。装好后，你用大白话说想要什么图，AI 会按照 DeepRouter 官方图像接口帮你生成或修改图片，并把图片保存到你电脑上的本地文件里。

- 官网 / 控制台：https://deeprouter.top
- 官方文档：https://deeprouter.apifox.cn
- 默认接口地址：`https://deeprouter.top/v1`
- 默认模型：`gpt-image-2`（官方文档里还有 gpt-image-1.5、gpt-image-1 等，能不能用取决于你的令牌分组）

本 Skill 只对接 DeepRouter 官方接口，不对接其他中转服务。

## 第一步：获取令牌（API Key）

1. 打开 https://deeprouter.top ，注册并登录。
2. 在「钱包」里按需充值。
3. 在「令牌」页面新建一个令牌，按需选择令牌分组，复制生成的令牌。
4. 不要把令牌发给任何人，也不要贴到聊天窗口里。

## 第二步：把令牌交给你的电脑（不是交给 AI）

二选一：

- **工具自带的密钥 / 环境变量设置**：如果你的 AI 工具有「密钥保管」「环境变量」之类的设置，把令牌存在那里，名字填 `DEEPROUTER_API_KEY`。
- **系统环境变量**：自己设置一个名为 `DEEPROUTER_API_KEY` 的环境变量，值是你的令牌。
  - macOS / Linux：在终端执行 `export DEEPROUTER_API_KEY='你的令牌'`（想长期生效，可写进自己的 shell 配置文件）。
  - Windows：在「系统属性 → 环境变量」里新建用户变量 `DEEPROUTER_API_KEY`。
  - 设置后，重启 AI 工具，让它读到新变量。

本 Skill 不会把令牌写进任何文件，也不会让你把令牌贴到对话里。

## 第三步：安装 Skill

1. 解压压缩包，得到 `deeprouter-image-api` 文件夹（里面有 `SKILL.md`）。
2. 按你所用 AI 工具自己的说明，把这个文件夹添加为 Skill。不同工具的界面和放置位置都不一样，请以该工具的官方说明为准；并不是所有 AI 应用都支持本地 Skill。

> DeepRouter 文档里的「各种插件/软件使用教程」讲的是如何把某个客户端的接口地址配置成 `https://deeprouter.top/v1`，那是「配置 API」，和「安装 Skill」是两回事。

## 第四步：说出你的需求

比如：

> 用 DeepRouter 帮我生成一张 1024x1024 的图：雪山脚下的湖边，一个小人在钓鱼，水彩风格。

AI 会先提醒你「请求发出后可能会扣费」，然后只发一次请求，把图片保存到本地，并告诉你文件路径。

想改尺寸、画质或格式，直接说就行，比如「横版 1536x1024」「画质 high」「保存成 jpeg」。

## 还能做什么

- **改图**：给 AI 一张本地图片，告诉它怎么改（换背景、改风格、合并多张图等）。可以附带蒙版（mask）只改局部。
- **查看可见模型（可选）**：AI 可以帮你列出令牌能看到的模型列表。注意：列表里有，不代表一定能生成成功；具体能用哪些、多少钱，以控制台「模型广场」和令牌分组说明为准。
- **GIF 动图 / SVG 矢量图（进阶、非官方完整文档）**：官方文档目前只写了 png / jpeg / webp 静态图。GIF 和 SVG 只有 2026-11-16 的少量实测记录，参数和效果都不保证，随时可能变化或失败。只有你明确要求时 AI 才会尝试，并会先说明风险。
- **Gemini 原生生图（仅作说明，未验证）**：官方文档有 Gemini 原生图片接口（`POST https://deeprouter.top/v1beta/models/{model}:generateContent`）。它的鉴权方式和完整可用请求都**没有经过验证**，所以 Skill 不提供可直接运行的示例，AI 也不会自行尝试；需要时请先对照官方页面 https://deeprouter.apifox.cn/489001914e0.md 核实。

## 本 Skill 不会做的事

- **不会自动查余额**：官方没有提供程序化的余额接口。官方文档里提到一个网页查询表单，需要你自己在浏览器里打开、自己粘贴令牌；AI 不会替你提交令牌到任何网站。
- **不会自动重试、不会自动换令牌、不会自动换线路、不会同时发多个生成请求。** 失败或超时后，是否重新发送由你决定。
- **不承诺价格、耗时和链接有效期。** 价格以控制台「模型广场」「钱包」和令牌分组说明为准。

## 常见问题

**令牌存在哪里？**
存在你自己设置的环境变量 `DEEPROUTER_API_KEY`，或者 AI 工具自带的密钥保管里。Skill 文件夹里没有、也不会写入任何令牌。

**会扣费吗？**
请求一旦发出就可能计费；部分失败或超时的请求也可能已经计费。所以 AI 只会在你明确要求生成或改图时才发请求，而且只发一次。

**报错了，先看什么？**
只看 HTTP 状态码（401 / 403 / 404 等）不足以判断原因。同一个状态码可能来自：鉴权、账号或令牌状态、令牌分组 / 权限、地区或入口地址、请求路径、模型是否可用等。AI 只会引用**脱敏、截断后**的上游 `code` / `type` / `message`（不含令牌、请求头、带签名的链接或 Base64），并给出可能的检查方向，而不会断定是某一个原因。

**提示 401？**
可以依次检查：令牌是否填对、是否已删除或停用（控制台「令牌」页面）；账号状态是否正常；接口地址是否是 `https://deeprouter.top`、路径里有没有写成 `/v1/v1`。不一定就是令牌错了。不要把令牌贴到聊天里。

**提示 403？**
可能是账号或令牌状态、令牌分组 / 权限不包含该模型、地区或入口地址，也可能是余额不足。只有当报错信息明确写了「余额不足」或类似含义时，才建议去控制台「钱包」充值；否则请先检查令牌、账号状态、分组 / 权限、模型、地区 / 入口地址。

**提示 404？**
可能是请求路径或接口地址不对（例如写成了 `/v1/v1/...`），也可能是该模型对你的令牌分组不可用、模型已更名或下线。请核对完整地址，并在「模型广场」和令牌分组里确认模型；不一定是模型名写错。

**提示 429？**
请求太频繁或上游繁忙，稍等一会儿再自己决定是否重发。AI 不会自动重试。

**提示 5xx 或超时了怎么办？**
5xx 和超时都不代表没有处理，请求可能已经计费。AI 不会自动重试；先确认后再自己决定是否重新发送（重新发送是一次新的、可能计费的请求）。

**图片链接打不开了？**
官方没有说明返回链接能保留多久。Skill 默认会立刻把图片保存到本地，请以本地文件为准。

**图片生成成功了，但下载 / 保存失败（比如下载链接返回 403）？**
（本节适用于 `deeprouter` 命令行内置的 1.0.2 版；之前单独发布的 1.0.1 压缩包没有这个功能。）
这时生成请求本身已经成功、可能已经计费。附带的脚本不会重新发送生成请求，也不会自动重试下载，而是：

- 已经保存好的图片照常保留，不会覆盖你已有的文件；
- 把还没下载下来的**完整结果链接**存进输出目录里的一个本地受限文件 `deeprouter-download-recover-时间.json`（文件权限 0600，脚本新建的目录 0700），并告诉你它的路径；里面不含令牌、请求头、响应原文或 Base64；
- 屏幕上的日志仍然脱敏，只显示下载地址的域名和状态码，不显示带签名的链接。

之后如果你想再试一次下载，可以让 AI 运行（只重试下载，不会再发生成请求，不需要令牌，也不会把令牌发给下载地址）：

`python3 scripts/deeprouter_image.py recover --from 恢复文件路径`

注意：

- recover 不能保证解决上游下载链接的 403，也不说明 403 的原因；链接可能已过期或被拒绝。
- 恢复文件里是可以直接下载图片的完整链接，请当作私密文件：不要提交到 git，不要发到聊天里，用完可以删掉（下载成功后脚本不会自动删除，会提醒你）。AI 只会告诉你文件路径，不会把文件内容或带签名的链接贴进对话。
- 在 Windows 上，0600 / 0700 只能尽量设置，文件仍沿用所在文件夹的 NTFS 权限，同一台电脑上有权限的其他账户可能能读到；恢复文件在任何系统上都没有加密。
- 脚本只从公网 HTTPS 地址下载，会拒绝 localhost、内网 / 链路本地 / 云元数据地址等链接。

**换别的接口地址行吗？**
官方文档列出了几个备用入口（如 `https://www.deeprouter.top`、`https://us.deeprouter.top`）。默认用 `https://deeprouter.top`；只有你明确要求时才会换，并且不会自动来回切换。

**报错看不懂？**
AI 会结合状态码和脱敏后的上游报错，列出可能的原因和检查方向（不会只凭状态码下结论）。更多帮助请查看官方文档 https://deeprouter.apifox.cn 或控制台。
